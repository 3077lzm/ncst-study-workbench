# 华理学习台

面向华北理工大学冶金与能源学院能源动力类大一新生的学习打卡与保研执行 PWA。工作台内置 2026-2027 学年第一学期课表、课程优先级、每日任务、专注计时、周复盘、四级准备和推免规则提醒。

## 本地运行

项目不需要安装依赖。使用仓库所在电脑上已有的 Node.js 启动：

```powershell
node server.mjs
```

浏览器访问：

```text
http://127.0.0.1:4173
```

如果系统没有全局 Node.js，可使用：

```powershell
C:\Users\lzm30\Desktop\日历\.tools\node-v22.19.0-win-x64\node.exe server.mjs
```

## iPhone 安装

1. 把本仓库发布到 GitHub。
2. 在仓库的 `Settings > Pages` 中选择 `GitHub Actions`。
3. 推送 `main` 分支后，工作流会发布静态站点。
4. 用 iPhone Safari 打开 Pages 地址。
5. 点击“分享”并选择“添加到主屏幕”。
6. 从主屏图标启动后，应用会以独立窗口显示。

工作台采用本地优先设计，打卡、计时、课程进度和复盘保存在浏览器本地，不会自动上传。

## 数据

- `data.js`：2026-2027 学年第一学期课表和课程元数据。
- `app.js`：工作台状态、打卡、计时、课程优先级和复盘逻辑。
- `sw.js`：离线缓存。
- `manifest.webmanifest`：PWA 安装配置。
- `冶金与能源学院推免实施细则-2025.docx`：学院公开细则原件。
- `保研学习计划.md`：当前执行标准与阶段计划。

## 自定义

在“设置”中修改每日专注目标、每周目标和专业名称。课程优先级和每周固定学习节奏可在 `app.js` 的 `COURSE_PROFILES` 与 `WEEKLY_PLAN` 中调整。
